- **2023-09-30 → now** — `scope-generic-command-paragraph`: Since 2023-09-30 all =cmd paragraphs (other than =pod, =cut, =begin/=end, =for) are parsed as generic command_paragraph nodes with a command token matching /=[a-zA-Z]\S*/.
