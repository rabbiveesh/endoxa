## Project scope over time

_Each row is the project's scope as believed during that window (`valid_time`). A later scope belief `supersedes` the earlier — scope expansion is non-destructive revision._

- **2007-02-07 → 2008-11-20** — `project-scope-v1-hashref-or`: In SQL::Abstract v1.x, hashrefs in WHERE clauses used OR as the default inter-key logic (matching the constructor default `logic => 'OR'`).
- **2008-11-20 → now** — `project-scope-v1-hash-and`: Since at least v1.50 (2008), hashrefs in WHERE clauses are ANDed by default (the `logic` option still defaults to OR for arrays, but hashref keys are always ANDed).

The name means 'opening up' (unwrapping), never adding.
